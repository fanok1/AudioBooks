**Больше книг в вашей повседневной жизни.** AudioBooks — бесплатное приложение для Android, которое помогает находить и слушать аудиокниги из нескольких онлайн-каталогов. Включайте истории по дороге на работу, скачивайте книги перед поездкой или засыпайте под любимую озвучку с таймером сна.

Идея проста: объединить поиск книг, личную библиотеку и удобное прослушивание в одном приложении. Выбирайте классику, фантастику, детективы, мемуары, книги по бизнесу и саморазвитию, произведения школьной программы, сказки и стихи для детей, а затем продолжайте слушать с того места, где остановились.

## Возможности

- **Находите интересные книги.** Просматривайте каталоги по жанрам, авторам и исполнителям, ищите по выбранным источникам, знакомьтесь с сериями и рекомендациями, если они доступны.
- **Слушайте онлайн и офлайн.** Включайте книгу сразу или заранее скачивайте главы. Управляйте загрузками и следите, какие книги сохранены полностью, а какие — частично.
- **Возвращайтесь к прослушиванию.** Плеер запоминает место остановки и продолжает с него, история помогает найти прослушанные книги, а избранное — сохранить понравившиеся.
- **Выбирайте удобный темп.** Меняйте скорость, перематывайте на 10 секунд назад или на 30 секунд вперёд и слушайте в фоновом режиме.
- **Отдыхайте с книгой.** Таймер сна остановит книгу в выбранный момент, а в следующий раз она продолжится с этого места. Звучание можно настроить эквалайзером.
- **Настраивайте под себя.** Выберите светлую, тёмную или чёрную тему, измените вид списка, включите родительский контроль, создайте резервную копию данных приложения или восстановите её.
- **Слушайте на большом экране.** Поддерживаются смартфоны, планшеты и Android TV.
- **Открывайте заблокированные каталоги.** Если сайт-источник недоступен в вашей стране, включите встроенный прокси в разделе **Настройки → Прокси**: через него идут страницы, аудио, скачивание и обложки. Прокси работает, только пока доступен его сервер.

### Источники книг

В приложении доступны **Akniga, Книга в ухе, ИзиБук, AudioBook-mp3, База Книг, Книгоблуд, Audioboo, Отрубин, Полекниг, уКниг, Аудиокниги.fun, Aknig.xyz и Аудиокнига Life**. Каталог для просмотра выбирается в разделе **Настройки → Источник**, а сайты для поиска — в разделе **Источники поиска**.

Книги и сведения о них загружаются с выбранных сайтов. Наличие произведений, рекомендаций и отдельных возможностей зависит от источника и доступности сайта в вашей сети.

## Установка

1. Скачайте APK из [последнего релиза на GitHub](https://github.com/korvin2000/AudioBooks/releases/latest) (`AudioBooks-<версия>.apk`) или из раздела «Скачать» первого сообщения [темы на 4PDA](https://4pda.to/forum/index.php?showtopic=978445).
2. Откройте APK на Android-устройстве. Если Android запросит разрешение, разрешите установку из браузера или файлового менеджера, которым вы воспользовались, и завершите установку.
3. Запустите **AudioBooks** и выберите каталог в разделе **Настройки → Источник**.

В каждом релизе на GitHub есть файл `SHA256SUMS.txt` с контрольными суммами. Сборки из разных мест (GitHub, 4PDA, устаревшая версия в [RuStore](https://apps.rustore.ru/app/com.fanok.audiobooks)) могут быть подписаны разными ключами, и Android не обновит одну сборку другой. Чтобы перейти на другую сборку, создайте резервную копию в разделе **Настройки → Резервное копирование**, удалите приложение, установите новый APK и восстановите копию.

## Первое прослушивание

1. Откройте **Аудиокниги** или **Жанры** либо найдите книгу по названию, автору или исполнителю.
2. Перейдите в карточку книги, прочитайте описание и начните воспроизведение. Нажмите на звёздочку, чтобы добавить книгу в **Избранное**.
3. Для прослушивания без интернета заранее скачайте нужные главы, дождитесь окончания загрузки и откройте книгу в разделе **Загруженные**. Настройка **Офлайн** скрывает главы, которые ещё не скачаны.
4. Вернитесь к книге через **Историю**, чтобы продолжить с сохранённого места.

## Помощь и обратная связь

- **Вопросы и общение:** [тема на 4PDA](https://4pda.to/forum/index.php?showtopic=978445).
- **Знакомство с приложением:** [видео на YouTube](https://www.youtube.com/watch?v=MlqR32Finf0).
- **Ошибки и идеи:** [GitHub Issues](https://github.com/korvin2000/AudioBooks/issues). При проблемах с воспроизведением или скачиванием укажите версию приложения и Android, источник, ссылку на книгу и действия для повторения ошибки.
- **Связь с разработчиком приложения:** пункт **О программе → Написать автору**.

**Если что-то не работает**

- **Каталог не загружается:** проверьте соединение и попробуйте другой источник. Если сайт заблокирован в вашей стране, включите **Настройки → Прокси**.
- **Воспроизведение прерывается при выключении экрана:** отключите для приложения оптимизацию батареи.
- **Смена устройства или переустановка:** сначала воспользуйтесь пунктом **Настройки → Резервное копирование**; скачанные аудиофайлы сохраните отдельно.

Приветствуются сообщения об ошибках, улучшения инструкций и переводов, а также небольшие, целевые pull request. Крупные изменения лучше сначала обсудить в issue. ## Сборка из исходников

**Нужны:** JDK 17 и Android SDK с платформой 36 (оба входят в Android Studio). Gradle 8.13 загружается обёрткой Gradle автоматически.

```bash
git clone https://github.com/korvin2000/AudioBooks.git
cd AudioBooks
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

В Windows используйте `gradlew.bat`. Отладочный APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Приложение находится в модуле `app/`: код на Java — в `app/src/main/java`, экраны и тексты — в `app/src/main/res`, тесты — в `app/src/test` и `app/src/androidTest`.

- **Релизные сборки** подписываются ключом, описанным в локальном файле `keystore.properties`, который не попадает в git (см. [пример](keystore.properties.example)).
- **Релизы** публикуются через GitHub Actions: тег `v<versionName>` (например, `v7.3`) запускает [workflow Release](.github/workflows/release.yml), который собирает, подписывает и публикует APK и App Bundle.
- **[Руководство разработчика](docs/howto.md)** (на английском) описывает настройку окружения, тесты, подпись, секреты CI, выпуск релизов, эмулятор и отладку.
